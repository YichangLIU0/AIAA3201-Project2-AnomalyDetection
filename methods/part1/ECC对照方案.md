# ECC 配准对照（固定方案）

先将整体最相近的正常模板移动到测试图位置，再计算与原基准完全相同的差异图和分数。模板选择仍使用原基准的 RGB 描述子和八个参考旋转；不重新挑选有利的参考图。

本轮预先固定为 **8-shot、六类、seed 0/1/2，共 18 组**，不是四个 shot 的 72 组。所有测试图参加评价，每类重新用同样 20 张校准图计算 ECC 方法自己的 95% 阈值。原有未配准基准、预测和成绩保持冻结。选择单一 shot 是为完成明确的配准对照，并控制本机原尺寸预测存储量。

## 固定设置

- 输入处理、参考、差异、平滑、形态学、最高 1% 图像分数、原尺寸像素评价均沿用基准。
- OpenCV ECC 使用 Euclidean（平移与旋转）模型；灰度缩到最长边 224，最多 50 次迭代、epsilon=1e-5、高斯核 5、初值单位矩阵。
- 测试图作为 `templateImage`，参考作为 `inputImage`。变换矩阵经精确比例换算回输入尺寸，用 `WARP_INVERSE_MAP` 移动参考图；测试图和 GT 不动。
- 接受范围预先固定：残余旋转最多 30 度，中心位移每方向最多输入尺寸 15%，有效重叠至少 75%，有效区域内灰度相关性不得下降。
- 边界之外保留未配准参考对应像素，不复制测试图、不屏蔽 GT、不将边缘误差人为设为零。
- 不收敛、常量图、非有限参数、超限变换、重叠不足或相关性下降时回退未配准参考。每张图记录状态、原因、矩阵、相关性及有效区域比例。
- 设置由几何常识和合成平移/旋转测试固定，不依据本轮 ECC 正式测试成绩反复选择参数。基准困难案例用于提出配准方向；本轮是同一公开测试集上的后续探索，不能宣称对未见数据的独立泛化验证。

API 方向和异常行为依据 [OpenCV 官方说明](https://docs.opencv.org/4.x/dc/d6b/group__video__track.html)。合成测试覆盖方向、原尺寸缩放换算、旋转、边界回退、不收敛及超限。

## 运行

在仓库根目录运行，环境沿用 Template：

```powershell
python -m unittest discover -s methods/part1/tests -v
python -u -m methods.part1.run_ecc --data-root 'E:/你的路径/VisA_pytorch/1cls'
```

程序需要本机已有 `outputs/part1_template_v1/` 的对应 18 组基准记录，逐图核对参考选择一致。新的大体积原始预测存入 `outputs/part1_ecc_8shot_v1/`；轻量指标、完整配准日志和预测清单存入 `results/part1_ecc_8shot/`。18 组约需额外 16 GiB，另保留至少 5 GiB 空间。

计时包含读图、选模板、ECC 求解、接受/回退检查、差分及原尺寸插值；不含磁盘保存及指标评价。当前 CPU 四个 OpenCV 线程，无 GPU 分配。报告成功/回退频率、速度代价及每类改善或退化，不将回退图排除，也不保证配准一定提升成绩。
