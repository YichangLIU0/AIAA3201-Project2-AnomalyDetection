# Template 基准：从这里开始

大白话讲：先拿几张正常产品图当样板。测试图与最接近的样板比较，差得越大的地方越亮；整张图的分数超过正常图算出的阈值，就判成异常。

这个方法简单、容易解释，但产品位置变化、外形不同、阴影变化也可能让差异图变亮。正式结果要如实展示这些局限。

## 已经写好的内容

- `template.py`：选样板、算差异、平滑和形态学处理。
- `run_template.py`：按公共清单跑六类、四个 shot、三个 seed，共 72 组；自动保存原尺寸预测和统一指标。
- `analyze_template.py`：仅在 72 组全部完成后生成完整性检查、汇总曲线、六个困难案例和中文结果说明。
- `requirements-experiment-lock.txt`：本轮正式运行所用的准确依赖版本；Python 为 3.13.5。

公共协议文件没有改动。B 的 DINO 和 AnomalyCLIP 可以继续使用当前公共接口，不需要等待 Template 完成才开始各自实验。

## 怎样在自己的电脑运行

以下命令都在 GitHub 项目的根目录执行。先确保六类数据已经准备好，再把命令里的数据路径替换成自己的。

```powershell
python -m venv .venv-template
.\.venv-template\Scripts\python.exe -m pip install -r methods/part1/requirements-experiment-lock.txt
.\.venv-template\Scripts\python.exe -m unittest discover -s methods/part1/tests -v

# 先跑一组真实正式实验，检查环境和数据路径
.\.venv-template\Scripts\python.exe -u -m methods.part1.run_template --categories candle --shots 1 --seeds 0 --data-root 'E:/你的数据路径/VisA_pytorch/1cls'

# 再跑全套；已经成功完成且设置相同的组会跳过
.\.venv-template\Scripts\python.exe -u -m methods.part1.run_template --data-root 'E:/你的数据路径/VisA_pytorch/1cls'

# 全部完成以后画图并检查完整性
.\.venv-template\Scripts\python.exe -m methods.part1.analyze_template --data-root 'E:/你的数据路径/VisA_pytorch/1cls'

# 可选：检查正常校准图对平移/增亮的敏感性，不作为新的正式测试成绩
.\.venv-template\Scripts\python.exe -m methods.part1.diagnose_sensitivity --data-root 'E:/你的数据路径/VisA_pytorch/1cls'
```

这里使用 CPU，不安装 PyTorch，也不占 GPU 显存。原尺寸浮点预测图约占 65 GiB，运行前还会检查是否有额外 5 GiB 空间。完整实验要等待一段时间，像素评价比整图分数评价慢。

## 去哪里看结果

- 正式完成数量：`results/part1_template/progress.json`。
- 每组指标及逐图判断：`results/part1_template/runs/`。
- 全套结束后的汇总：`results/part1_template/summary.csv`、`summary.json`。
- 全套结束并完成分析后的中文说明：`results/part1_template/实验结果与错误分析.md`。
- 原始预测图、图像哈希、校准分数、参考选择与耗时：`outputs/part1_template_v1/`。

GitHub 只上传代码、轻量指标、说明和案例图；大体积原始预测留在运行机器上。若只想查看结果，不需要重新跑实验或下载全部预测图。

不要把原来 `integration_only=true` 的 Candle 测试放进本轮正式汇总。也不要运行到一半修改被冻结的推理代码；更换方法要用新的输出目录、重新跑独立实验。

如果中途关闭，重新执行同一命令。完整预测已保存的组可以继续评价；若在写预测图时中断，保留该组的残留目录并将其移到其他位置，再重新运行该组。程序会拒绝直接覆盖这些未完成预测，避免混进旧文件。

## 还需要怎样改进

先看困难案例确认问题。如果热图主要亮在产品外轮廓，ECC 配准是下一步可以独立验证的方向。如果是正常产品本身形状差异很大，单纯配准可能仍不够，需要比较 DINO 等特征方法。不能看到测试集成绩低，就不断修改参数后挑最好的成绩上报。

ECC、Autoencoder 和 A 的其他 Part 3 任务需要单独实施和记录。本轮 Template 完成后也不能直接声称 A 的全部任务完成。
